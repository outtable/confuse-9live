# 我需要体验版或者采购工具该如何申请授权？
**由于应用中心包含多个应用，所以下面文档会告诉你该怎么找到申请授权入口**

## 一.下载应用中心

###1.登录 <a href="https://crab-ios.com/#download" target="_blank" rel="noopener noreferrer">小蟹iOS官网</a>，找到下载，选匹配版本的系统版本

###2.在应用中心中输入你的专用邮箱

<img src="https://crab-ios.com/docs/site/assets/images/snapshots/snapshot-76.png" width="60%">

## 二.通用版授权

###试用版版本如何申请？

1.首先找到注册码界面
>
<img src="https://crab-ios.com/docs/site/assets/images/snapshots/snapshot-77.png" width="60%">

2.输入你的bundle id（注意：这个bundle id请填写你加了自己调试设备的账号下的）

3.输入一个SDK名字，比如说“NiHaoSDK”（注意：这个名字最好按你的App名字+SDK形式的，避免跟别人冲突，要求全英文）

!!!tip
	注意一定要填写一个bundle id，不然会被打回


###月费版本如何申请？

1.找商务完成采购流程

2.首先找到注册码界面
>
<img src="https://crab-ios.com/docs/site/assets/images/snapshots/snapshot-77.png" width="60%">

3.输入一个SDK名字，比如说“NiHaoSDK”（注意：这个名字最好按你的App名字+SDK形式的，避免跟别人冲突，要求全英文）


!!!tip
	注意一个授权操作没有结束的情况下，你再申请一个授权会被拒绝
